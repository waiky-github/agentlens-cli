## 定价原则

1. **开源免费引流**：社区版功能完整覆盖核心审计能力（七层审计全部开放），任何开发者都能用 `pip install` 零成本上手。社区版本身就是最好的产品展示——用户用出价值后，自然会需要团队协作和管理功能。

2. **企业服务收费**：团队版和企业版收费的不是「审计能力」，而是**持续运营能力**——Web 平台、自动告警、漂移监控、SLA 保障。这些是生产环境长期运行必需的，也是企业愿意付费的。

3. **按需升级**：社区版 → 团队版 → 企业版，功能逐层递进。用户不会觉得被「故意阉割」，而是随着 Agent 系统规模增长自然需要更多管理能力。

4. **透明度**：所有功能边界清晰列出，不搞「联系我们报价」的模糊定价。客户可以在购买前完整评估社区版是否满足需求。

## 常见定价问答

**Q: 社区版会一直免费吗？**
A: 核心审计功能（七层审计）永久免费且开源。Web 平台、MCP Server、Watchdog 等运营功能作为团队版/企业版增值服务。

**Q: 团队版和企业版的核心区别是什么？**
A: 企业版多了 Watchdog 漂移监控、私有化部署、SSO 集成和 SLA 保障。简单说：团队版适合「我有一个 Agent 项目要管」，企业版适合「我有一堆 Agent 系统要合规」。

**Q: 可以按年付吗？有月付选项吗？**
A: 建议按年付费。月付模式建议价按年费的 1/10 上浮 20%（即团队版月付建议价约 ¥3,580/月，企业版月付建议价约 ¥11,760/月），具体以合同为准。

**Q: 开源协议是什么？有商业使用限制吗？**
A: 社区版采用 MIT 协议，无商业使用限制。团队版和企业版通过 Web 平台及运营功能提供增值服务，开源核心审计引擎不受影响。
