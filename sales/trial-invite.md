## 文案 B：正式版（适合邮件/群公告）

**主题：邀请试用 AgentLens Audit —— 多 Agent 协作审计工具（种子用户计划）**

【团队名】您好，

我们在做一个开源工具 **AgentLens Audit**（GitHub: waiky-github/agentlens-cli，PyPI: agentlens-audit 0.3.0），想邀请贵团队参与种子用户试用。

**它解决什么问题**

多 Agent 系统在生产环境跑起来后，团队普遍面临三个「黑盒」：
1. 协作过程不可见——任务怎么拆的、为什么派给这个 Agent、调了哪些工具，出了事无法回溯
2. 成本失控——重复调用、无效循环、大输出浪费，实测可避免成本 **63-76%**
3. 合规无据——网信办 2026-05 实施意见 + OWASP LLM Top 10 2026 都来了，但决策链路没有审计记录

**它做什么**

- 七层审计：协作图谱 / 决策审计 / 证据链 / 成本治理 / 影子智能体 / 决策权限合规 / CI 门禁
- 合规条款映射：发现自动关联法规（网信办 + EU AI Act + OWASP LLM Top 10 2026 + Agentic Top 10 + ACS）
- 成本预算告警：超阈值推飞书/webhook
- 修复闭环：标记已修复 + 连续 3 次验证才 verified（防假修复）
- 持续监控：watchdog 定期复检，发现新问题漂移，cron 可调度
- Web 仪表盘 + MCP Server（可接入 Claude Code / Cursor / Hermes）

**技术特点**：纯 Python 标准库，零第三方运行依赖，框架中立（Hermes / CrewAI / AutoGen / LangGraph / 统一事件流都支持），完全本地运行数据不出机器。

**种子用户权益**：免费试用、优先支持（问题直接反馈给我们）、影响产品方向。

**30 分钟上手**：pip install → demo 一键出报告 → 用你们自己的事件流跑真实审计（指南：仓库 docs/QUICKSTART.md）

## 使用提示

- 文案 A 适合熟人/私聊，文案 B 适合正式渠道
