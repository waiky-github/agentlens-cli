## 场景一：AI 应用公司的多 Agent 合规审计

### 痛点

一家做 AI 客服/AI 编程助手/AI 数据分析的公司，后端跑着 CrewAI 或 LangGraph 编排的多 Agent 系统。产品上线后，客户开始问：

- "你们的 Agent 做了什么决策？依据是什么？"
- "有没有可能泄露用户数据给不该看到的 Agent？"
- "网信办的新规要求 Agent 决策可追溯，你们怎么证明？"

团队翻遍日志只能看到零散的 API 调用记录，无法还原完整的决策链路。合规举证全靠人工拼凑，效率低且不可靠。

### 方案

接入 agentlens-audit，将 Agent 系统的运行事件流导出为 JSONL，一条命令完成七层审计：

- **Evidence 证据链**：每个结论的推导过程完整记录，可回溯到原始输入
- **Compliance 决策权限合规**：区分用户本人决策/用户授权/自主决策，确保 Agent 不越权
- **Regulations 合规条款映射**：自动关联网信办《智能体规范应用与创新发展实施意见》(2026-05)、EU AI Act、OWASP LLM Top 10 2026 等法规条款
- **Leakage 系统提示泄露检测**：覆盖 OWASP LLM08 Hidden Context Exposure

### 价值

- 合规举证从「人工翻日志」变成「一条命令出报告」
- 完整审计 11268 事件 → 727 findings 验真通过（VERIFIED），合规映射 0 unknown
- 审计报告为自包含 HTML，可离线归档，满足监管留存要求

## 场景二：企业 Agent 平台的运维治理

### 痛点

某大型企业的内部 Agent 平台接入了多个部门的 Agent 应用，每天运行数千次 Agent 调用。平台运维团队面临：

- 不知道哪些 Agent 在「空转」——重复调用、无效循环，实测可避免成本浪费 63-76%
- 担心有未登记的 Agent（Shadow Agent）在调用敏感工具
- 需要一个自动化的持续监控机制，而不是每次出了问题再手动排查

### 方案

部署 agentlens-audit 的 Web 平台 + Watchdog 持续审计漂移监控：

- **Cost 成本治理**：按 Agent 成本归因，自动发现大输出注入、重复调用浪费，实测可避免 63-76% 的成本浪费
- **Shadow 影子智能体检测**：发现未登记 Agent 和未授权工具调用
- **Watchdog 漂移监控**：设置每日 03:00 自动审计，对比基线发现新问题漂移，含多日漂移趋势历史，推飞书告警
- **Budget 预算告警**：单次审计总成本/预估浪费超阈值自动推送，含历史记录

### 价值

- 从「被动排查」到「主动监控」，问题发现时间从「用户投诉后」提前到「当天自动发现」
- 成本浪费可量化、可追溯，成本优化有据可依
- 生产环境每日自动审计 + 漂移推飞书已稳定运行

## 场景三：开源项目的 CI 质量门禁

### 痛点

一个开源 AI Agent 框架（如某种 LangChain 封装库）的维护者，每天收到大量社区贡献的 Agent 配置和工作流。维护者担心：

- 贡献者提交的 Agent 配置可能存在安全漏洞（提示泄露、越权决策）
- 人工审查效率低，需要一个自动化的「安全门禁」
- 需要给贡献者明确的修复建议，而不是只报错不给方案

### 方案

将 agentlens-audit 集成到 CI/CD 流水线：

- **Gate CI 门禁**：`agentlens-audit audit --input events.jsonl --gate`，违规超阈值非零退出码，直接阻断 CI
- **Remediation 修复建议**：每类 finding 配具体修复建议（action + detail + priority），贡献者可以照着改
- **Verify 修复回归验证**：mark-fixed 后连续 3 次审计缺席才 verified，复发即 regressed，防止假修复
- **Integrity 报告防篡改**：SHA-256 文档哈希链，确保审计结果未被篡改

### 价值

- CI 自动拦住不合规贡献，减少人工审查工作量
- 提供可操作的修复建议，降低社区贡献门槛
- 246 个测试全绿，七层审计逻辑经过充分验证

## 场景四：咨询/交付项目的验收审计

### 痛点

一家 AI 咨询公司为客户交付了一套多 Agent 系统（如基于 AutoGen 的企业知识库问答系统）。项目验收时，客户要求：

- 证明系统在测试期间的 Agent 行为符合设计要求
- 证明没有意外的工具调用或数据泄露
- 提供可归档的审计报告作为交付物的一部分

咨询公司之前只能靠截图和手动整理日志来应付验收，耗时且缺乏说服力。

### 方案

在交付前运行 agentlens-audit 的完整审计：

- **Graph 协作图谱**：可视化展示 Agent 协作全链路，客户一眼看懂系统怎么工作的
- **Decision 决策审计**：审批链合规检查，证明 Agent 决策流程符合设计规范
- **Evidence 证据链**：每个输出都有完整推导过程，满足「可解释性」要求
- **自包含 HTML 报告**：无外链资源，可离线打开，作为正式交付物归档
- **diff 基线对比**：对比不同版本的审计结果，展示优化效果

### 价值

- 审计报告成为交付物的一部分，提升交付专业度和客户信任
- 从「口头解释」变成「报告说话」，减少验收扯皮
- 作为增值服务，可以成为咨询公司的差异化竞争力
